# Format of Signature: ftSignatureFormat

The Middleware uses the same ftSignatureFormat in Greece as in all other countries, as described in the [Format of Signature: ftSignatureFormat](../../general/reference-tables/reference-tables.md#format-of-signature-ftsignatureformat) reference table of the Compliance Middleware.

## ftSignatureFormatFlag

Greece does not currently define additional signature-format flags beyond the shared set described in the Compliance Middleware reference table above. In practice, the Greek implementation uses `Text`, `Link`, and `QRCode` from that shared set.
