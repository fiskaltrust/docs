- **Internet:** a locally installed Middleware with a smart card signs receipts without an internet connection. A signing service and the hosted Middleware (SignatureCloud) need an internet connection.
- **Signature creation device not reachable:** the Middleware continues in failed mode, and the receipts are marked `Sicherheitseinrichtung ausgefallen`. Restore the device and have the operator send a Zero-Receipt from the POS system.
- **48-hour rule:** outages that exceed 48 hours must be notified to FinanzOnline. With a fiskaltrust.Carefree or Notification subscription, this is done automatically. For more information, see [FinanzOnline Management](../../../../../buy-resell/products/3rd-party/finanzonline-management.md).
- **Offline setups:** without an internet connection, the Zero-Receipt returns pending FinanzOnline notifications as AZTEC codes, which must be carried out manually.

For the POS system integration, see [Offline Handling (AT)](../../../../../../poscreators/middleware-doc/middleware-at-rksv/cash-register-integration/offline-handling.md).
