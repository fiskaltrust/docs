- **Internet:** a hardware TSE is connected to the device on which the Middleware runs. A cloud TSE and the CloudCashbox need an internet connection. For the hostnames of the cloud TSEs, see [Additional access permissions](../../../../../technical-operations/middleware/network-requirements.md#additional-access-permissions).
- **TSE not reachable:** the Middleware continues in failed mode, and the receipts are not signed by the TSE. Restore the TSE or the connection to it and have the operator send a Zero-Receipt from the POS system.
- **Remedy immediately:** the PosOperator must remedy the cause of every failure immediately (DE: unverzüglich). The law does not define a time frame.

For the POS system integration, see [Offline Handling (DE)](../../../../../../poscreators/middleware-doc/middleware-de-kassensichv/cash-register-integration/offline-handling.md).
