- **Connection:** a locally installed Middleware is reached over the local network, the CloudCashbox over the internet connection of the location.
- **During the failure:** the POS system issues receipts marked "electronic recording system failed" (DE: Elektronisches Aufzeichnungssystem ausgefallen) and buffers them.
- **Afterwards:** the POS system sends the buffered receipts to the Middleware. Have the operator send a Zero-Receipt to end late-signing mode.
- **Remedy immediately:** the PosOperator must remedy the cause immediately (DE: unverzüglich). The law does not define a time frame.

For the POS system integration, see [Middleware Not Reachable (DE)](../../../../../../poscreators/middleware-doc/middleware-de-kassensichv/cash-register-integration/middleware-not-reachable.md).
