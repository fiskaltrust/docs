| Step | Description |
|:----:|-------------|
|![Number 1](../../../../../images/numbers/circle-1o.png) |In the fiskaltrust.Portal, choose `Company info` > `Master data`. |
|![Number 2](../../../../../images/numbers/circle-2o.png) |Check that the fields marked with * contain correct and complete data. |
|![Number 3](../../../../../images/numbers/circle-3o.png) |Check the tax identification numbers against the explanations below the data fields. Observe the notes on notation, such as the number of digits and the omission of spaces, and whether one or more values are required; this varies from country to country. |
|![Number 4](../../../../../images/numbers/circle-4o.png) |Check the entered values with `Data Check` to the right of the data fields. |

*Table 1. Steps to check and complete the master data.*

| Data check result | Meaning |
|:-----------------:|---------|
|![Data Check symbol for an unchecked value](images/data-undone.png) |The value in the data field has not been checked yet. |
|![Data Check symbol for an invalid value](images/data-invalid.png) |The value is invalid. Hover over the symbol to see the description, change the value accordingly and run the data check again. |
|![Data Check symbol for a valid value](images/data-valid.png) |The value is valid. This does not protect against duplicates. |
