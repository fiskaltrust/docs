#### Outlets

![Outlets page in the fiskaltrust.Portal with the primary outlet, the CSV import controls, the button to add an outlet and the Edit button of an outlet marked 1 to 7](images/checking-outlets-23-02-07-DE.png)

*Figure 1. Outlets page in the fiskaltrust.Portal.*

| Step | Description |
|:----:|-------------|
|![Number 1](../../../../../images/numbers/circle-1o.png) |Choose `Company info` > `Outlets` and check the existing values. |
|![Number 2](../../../../../images/numbers/circle-2o.png) |If several outlets are missing, choose `Download demo CSV file`. |
|![Number 3](../../../../../images/numbers/circle-3o.png) |Open the CSV file, add the values and save it. Go back to `Company info` > `Outlets` in the fiskaltrust.Portal and select the file with `Choose` under `Import CSV file`. |
|![Number 4](../../../../../images/numbers/circle-4o.png) |Choose `Import`. The data is checked and listed on the `Bulk import of outlets` page. Choose `Proceed with valid outlets`. |
|![Number 5](../../../../../images/numbers/circle-5o.png) |If only a single outlet is missing, choose `+Add new outlet`. |
|![Number 6](../../../../../images/numbers/circle-6o.png) |`Edit Primary Outlet` changes the address values that you have checked in `Company info` > `Master data`. |
|![Number 7](../../../../../images/numbers/circle-7o.png) |To change the data of an outlet, choose `Edit`. |

*Table 1. Steps to check and edit outlets.*
