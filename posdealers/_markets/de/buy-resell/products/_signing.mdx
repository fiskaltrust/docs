:::info

This documentation uses the English term **Technical Security System (TSS)** for signing devices in Germany, instead of the German abbreviation **TSE** (Technische Sicherheitseinrichtung). Both terms mean the same.

:::

### Supported Technical Security Systems
The fiskaltrust.Middleware supports all certified TSSs currently available on the market:

**Hardware**:
- Swissbit USB
- CryptoVision/Bundesdruckerei
- Epson
- Diebold Nixdorf

**Cloud**:
- Swissbit Cloud
- Deutsche Fiskal
- fiskaly

Not all TSSs are available in the `Shop`, but it offers a mix of the most used cloud and hardware TSSs, as described in the following sections. TSSs of these vendors that you buy elsewhere also work with the Middleware.

:::tip Switching TSE

You can switch between vendors and types of TSEs if you buy the matching products. For detailed instructions, see the [knowledge base article KA-01112](https://portal.fiskaltrust.de/KBArticle#/KA-01112).

:::

### TSE-as-a-Service
TSE-as-a-Service is a yearly, subscription-based leasing model for **hardware and cloud TSSs**. **For the duration of the subscription**, it provides the hardware or the access credentials for the online service. When the subscription expires, you or your PosOperator return the hardware or renew the subscription.

You cannot buy TSE-as-a-Service as an individual product, only as part of a [fiskaltrust.Sorglos](../../../../buy-resell/products/bundles.md) bundle.

### Individual TSE products
In addition to [TSE-as-a-Service](#tse-as-a-service), fiskaltrust offers several TSE devices and products for individual purchase in the `Shop`.

#### Cloud TSSs
The following SaaS TSE platforms are currently available in the `Shop`:
- Swissbit Cloud
- fiskaly

#### Hardware TSSs
The following TSE devices are currently available in the `Shop`:
- Swissbit USB
- Cryptovision

:::caution

A TSE bought as an individual product works with only one Queue. To use several Queues with the same TSE, use TSE-as-a-Service as part of a [fiskaltrust.Sorglos](../../../../buy-resell/products/bundles.md) bundle.

:::

For more information, see [fiskaltrust products in Germany](https://fiskaltrust.de/produkte/).

:::tip Virtual Environments

In virtual environments, use cloud TSEs. For more information, see the [knowledge base article KA-01080](https://portal.fiskaltrust.de/KBArticle#/KA-01080).

:::
