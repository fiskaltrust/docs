### CloudCashbox

CloudCashbox is fiskaltrust's SaaS Middleware platform. It offers the same features as a locally hosted Middleware, but you do not install or maintain any software or TSE. Your POS system needs a working Internet connection to communicate with the CloudCashbox over an encrypted **HTTPS** connection.

For more information, see [CloudCashbox](../../../../technical-operations/middleware/launchers/cloudcashbox.md).
