
| Field | Description | Mandatory |

| AccountName            | Company name, written exactly as in the commercial register. | yes |

*Table 1. Columns of the CSV file for the bulk invitation (France).*

<sup>1</sup> Optionally, you can also provide a dedicated e-mail address for invoices in `Company info` > `Master data` (`Primary Billing E-Mail`).

<sup>2</sup> The tax identification numbers are not mandatory for the invitation process. But they are the basis for correct cash register management and a prerequisite for using third-party services.

<sup>3</sup> Not included in the current demo CSV file. Older CSV files with this column can still be imported; the column is ignored.
