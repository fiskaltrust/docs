:::caution

This example uses REST as a communication protocol and requires a REST helper to be enabled in your CashBox.

:::

To send an echo request, send a `POST` request to the path `/json/Echo` of the configured Middleware URL. The request body is a JSON string that contains the message you want the Middleware to return.

For example, to send `Hello fiskaltrust.Middleware!`, use the following request body:

```json
"Hello fiskaltrust.Middleware!"
```

The following HTTP request sends this string to the Middleware:

```http
POST /json/Echo HTTP/1.1
Host: localhost
Content-Length: 31
Content-Type: application/json

"Hello fiskaltrust.Middleware!"
```

The response has the status code `200` and contains the exact string you sent in the response body.

:::info

For the full request details, parameters and a curl example, see the [Echo request in the Middleware samples](https://middleware-samples.docs.fiskaltrust.cloud/#4a36918f-8950-4893-81c9-1778071d4f98).

:::
