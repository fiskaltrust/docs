- **Internet:** the Queue signs the receipts itself, so a locally installed Middleware signs receipts without an internet connection. The hosted Middleware (ChaîneCloud) needs an internet connection.
- **Middleware not reachable:** the POS system prints "mode dégradé" receipts and sends them to the Middleware once it is reachable again. Have the operator send a Zero-Receipt afterwards.

For the POS system integration, see [Offline Handling (FR)](../../../../../../poscreators/middleware-doc/middleware-fr-boi-tva-decla-30-10-30/cash-register-integration/offline-handling.md).
